# CE-1-02 — Profile loader: one engine, several asset classes

**Why:** `factory.py` hard-codes the NSE equity universe, benchmark, calendar, cost model and state dir at module level. The Capital Engine needs the same engine to run a defensive-ETF class and a crypto class with their own universe/costs/state, with ZERO change to the equity arena. This is the smallest change that makes that possible: a JSON profile selected by an environment variable, defaulting to today's behaviour.
**Executor:** CLAUDE_CODE (class B). Fable review: YES (financial core).
**Scope:** `profiles/__init__.py` (`load_profile(name)`), `profiles/equity_nse.json`, `factory.py` (only the constant-definition block: read `FACTORY_PROFILE` env, default `equity_nse`, override `UNIVERSE`, `MACRO_PROXIES`, `BENCHMARK`, `STATE_DIR`, `VARIABLE_COST_PER_SIDE`, `DP_CHARGE_PER_SCRIP`, calendar flag `TRADES_WEEKENDS`, and the tax-rate constants), `tools/health_check.py` (+ `check_profile_integrity`).
**Do not touch:** `RULES`, `LADDER`, `COST_PER_SIDE` literals; any `sig_*` function; `update()`/`report()` bodies except reading the calendar flag; `factory_state/ledger.json`.
**Dependencies:** CE-1-01 (golden master must exist and pass before AND after).

## Design rules (binding)
- `profiles/equity_nse.json` holds exactly today's values. `factory.py` with no env var must produce the same golden-master fingerprint.
- A profile may NOT carry `rules`, `ladder` or `cost_per_side` keys for `equity_nse`; `check_profile_integrity` fails if present. Other profiles MAY carry `rules`/`ladder` proposals, but they are inert until the profile has `"enabled": true`, and enabling is Het's decision (financial parameters → NEEDS HET).
- Non-default profiles use `STATE_DIR = factory_state/<profile>/` so the equity ledger path never moves.
- `TRADES_WEEKENDS: true` only changes which rows `fetch_prices()` keeps; the idempotence guard stays.

## Steps
1. Write the profile JSON by copying the literals; write the loader (stdlib `json`, no new dependency).
2. Patch the constants block; run golden master → identical fingerprint. Paste it.
3. Run with `FACTORY_PROFILE=does_not_exist` → clean error, exit 1.
4. Add `check_profile_integrity` to `health_check.run_all` and the forbidden-keys test.

## Acceptance
- Golden master fingerprint unchanged (before/after SHA pasted).
- `FACTORY_PROFILE=equity_nse` and unset produce identical ledgers.
- `health_check.py` passes; the forbidden-key case is covered by a unit test.

**Rollback:** revert the single commit; the profile file is inert without the loader.
