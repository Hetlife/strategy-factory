# CE-6-01 — Archive every pull and every run (GitHub is the record)

**Why:** `docs/capital_engine/DATA_ARCHIVE.md`. Today the raw pull, skipped runs and the weekly report text are not kept (Actions logs expire after 90 days).
**Executor:** CLAUDE_CODE (class B). Fable review: NO — additive, wrapped so it cannot break a run; the orchestrator reviews.
**Scope:** new `archive.py`; `factory.py` (ONLY: (a) in `fetch_prices()` stash the pre-ffill panel in a module global `LAST_RAW`; (b) replace the `if __name__ == "__main__"` block with `main(cmd)` + a thin call); `tests/test_archive.py`; `README.md` (a short section).
**Do not touch:** `update()`/`report()` bodies, `RULES`/`LADDER`/`COST_PER_SIDE`, the kill-switch code, `factory_state/` contents, workflows (`git add factory_state` already commits the archive), the equity golden file (must stay unchanged — do NOT regenerate).
**Dependencies:** none.

## Design (binding)
- `archive.py` (stdlib + pandas), all paths under `os.path.join(state_dir, "archive")`:
  - `record_pull(state_dir, raw, pulled_at, pull_id, keep_last=6)`: `raw` = the pre-ffill Close panel (DataFrame, index dates, columns tickers). For the last `keep_last` rows and every ticker, append a row to `pulls/YYYY-MM.csv` (month of the PANEL date) with columns `panel_date,ticker,close,first_seen_utc,pull_id` ONLY when that (panel_date,ticker) is absent from the latest stored value or its value differs (NaN→value, value→NaN and value→other value all count as changes; NaN is written as an empty field). Read the current and previous month's files to find the latest stored value per key. Create the header on a new file. Append, never rewrite.
  - `record_run(state_dir, record)`: append one JSON object (sorted keys) as a line in `runs/YYYY-MM.jsonl` (month of `ts_utc`).
  - `save_report(state_dir, text, day)`: write `reports/<day>.txt` (overwrite the same day).
  - `safe(fn, *a, **k)`: call, and on ANY exception print `[archive warning] ...` and return None. An archive failure must never change a run's exit code or output flow.
- `factory.py`: `fetch_prices()` sets `LAST_RAW = px.copy()` right after the download and BEFORE `dropna/ffill` (declare `global LAST_RAW`; default `LAST_RAW = None` at module level). Then:
  ```
  def main(cmd):
      # tee stdout so the outcome can be derived without touching update()/report()
      ...call {"update": update, "report": report}[cmd]() inside try/except BaseException...
      derive outcome from the captured text: "KILL SWITCH ACTIVE" -> killed (write NOTHING, return); "PHANTOM SKIPPED" -> note phantom_skipped_date; "Arena update SKIPPED" -> skipped; "Arena updated <date>" -> recorded (recorded_date); "Arena update FAILED" or SystemExit(code!=0) -> failed; an exception -> error:<ExceptionName>
      if update ran and LAST_RAW is not None and outcome is not killed: safe(archive.record_pull, STATE_DIR, LAST_RAW, ...)
      safe(archive.record_run, STATE_DIR, {ts_utc, profile, cmd, outcome, recorded_date, phantom_skipped_date, n_tickers (columns of LAST_RAW), n_nan_last_row, ledger_sha256 (sha256 of STATE_DIR/ledger.json or null), git_sha (env GITHUB_SHA), run_id (env GITHUB_RUN_ID), event (env GITHUB_EVENT_NAME), versions {python, pandas, numpy, yfinance if importable}})
      if cmd == "report": safe(archive.save_report, STATE_DIR, captured_text, today_utc_date)
      re-raise the original SystemExit/exception so the exit code is unchanged
  if __name__ == "__main__": main(sys.argv[1] if len(sys.argv) > 1 else "update")
  ```
  The tee must also print to the real stdout live (the workflow logs stay identical). Python 3.10 compatible.
- No change to what `update()`/`report()` compute or write.

## Acceptance (tests/test_archive.py, no network)
1. `record_pull`: first call writes all rows for the last 6 dates; an identical second call writes nothing; a revised value writes exactly one row; NaN→value and value→NaN each write one row; rows split across two months go to the right files; a missing/unwritable dir does not raise through `safe`.
2. `record_run` appends valid JSON lines in order; `save_report` overwrites same-day.
3. `factory.main("update")` in a temp factory copy (reuse `tests/test_golden_master._load_factory_copy`, monkeypatch `fetch_prices` to set `LAST_RAW` and return a synthetic panel): writes a runs line with outcome `recorded` and the right date; a second call on the same panel writes outcome `skipped`; a phantom last row writes `phantom_skipped_date`; an empty download writes outcome `failed` and still exits 1; a KILL file writes NOTHING under `archive/`; `main("report")` writes the report text file.
4. Full suite OK twice; the equity golden fingerprint is unchanged (the ledger is identical with and without the wrapper).
