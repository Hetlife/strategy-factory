# CE-4-02 — Kill switch: one file stops every write path

**Why:** Het asked for a system that can run real money eventually. The first piece of real-money infrastructure is the ability to stop everything instantly, for free, without a model: a file.
**Executor:** CLAUDE_CODE (class B). Fable review: YES (touches `update()`/`report()` entry).
**Scope:** `factory.py` (`update()` and `report()` first line: if `factory_state/KILL` exists → print the file's contents and return before any state change), `advisors.py` same, `.github/workflows/*.yml` (step that prints the KILL status), `tools/health_check.py` (`check_kill_switch`: WARN while present), `README.md` (how to pull it: `git commit` an empty `factory_state/KILL` with a reason, via the phone/GitHub UI — no session needed).
**Do not touch:** anything else in `update()`/`report()`.
**Dependencies:** CE-1-01 (golden master unchanged when no KILL file).

## Acceptance
- Golden master unchanged. With the file present, 40 cycles produce a byte-identical ledger and 40 printed KILL notices.
- Health check reports the switch while present.
